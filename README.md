# Music Player (mPlayer) - CodeAlpha

A fully functional music player web application built as part of my Frontend Development Internship at CodeAlpha.

## 🚀 Features
* **Audio Controls**: Play, pause, skip to next, and previous tracks seamlessly[cite: 1].
* **Track Info & Cover Art**: Displays current song title, artist name, and album cover art[cite: 1].
* **Interactive Progress & Volume Bars**: Real-time progress tracking, seeking, and custom volume control[cite: 1].
* **Local Upload & Playlist Support**: Upload local audio files and manage favorite tracks[cite: 1].
* **Bonus Features**: Shuffle mode, loop/repeat functionality, and real-time search[cite: 1].

## 🛠️ Tech Stack
* **HTML5**: Semantic layout and audio element integration.
* **CSS3**: Modern Spotify-inspired dark UI styling with responsive layouts.
* **JavaScript**: Audio state management, event listeners, and dynamic UI rendering.
